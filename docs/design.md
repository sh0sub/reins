# Design tokens and scope

- Source: Peerly design system (`peerly-mockup/docs/design/05-design-system.md`, `design-tokens.json`), metadata version **0.1.0**, checked 2026-10-09, status "proposal".
- Pinned copy: `apps/web/src/design/design-tokens.json`. CSS is generated by `pnpm tokens` into `apps/web/src/app/tokens.css` (aliases resolved, missing/circular aliases rejected; `apps/web/test/tokens.test.ts` fails if the CSS drifts from the JSON).
- Applied: core `semantic` + `component` layers only. The `themes.peerly` brand (logo, wordmark, product name) is **not** used; Reins keeps its own name.
- Product colour (2026-10-29): the plan's 07 mockup section ("디자인 방향: 조용한 관제실") defines the Reins palette, so
  `apps/web/src/app/theme.css` overrides the Peerly colour tokens: primary PayPal navy #003087, canvas #f7f9fc, ink #14213d,
  success #1b8a5a, warning #c77d12 (text uses #8a560b for 5.9:1 contrast), danger #c62f2f. Spacing, radius, type scale,
  focus ring and motion stay Peerly. Only theme.css holds hex values (AG Charts canvas mirrors them in SpendChart.tsx).
- Layout per mockup: sidebar 216 + 56px top bar (page name, live SSE state, pending shortcut); S5 approvals = queue 360 +
  detail; S2 agents = list 280 + mandate panel; S4 ledger = KPIs + AG Charts bar + AG Grid (row height 40).
- Fonts: Manrope / Noto Sans KR are referenced in the stack but not loaded; system fallbacks render until a font loading decision is made.
- Layout: sidebar 216px at >= 950px, compact top bar below; one primary action per screen (Approve in the inbox, Save in the mandate editor, Verify/Continue in setup); 48px touch targets; empty/loading/error states on every list.
- Verified in Chrome at 1519px wide (inbox with a pending item, Ask agent round trip, approve -> All clear; agents; ledger + row expansion; setup). 360/720 viewports and real phones not verified (window resize did not apply).
- S7 overview (2026-10-31): KPI row + cap bars (link to ledger `?agent=`) + AG Charts donut + feed + weekly summary card. Donut uses the dataviz reference categorical palette (`--reins-series-*` in theme.css, CVD-validated; contrast WARN mitigated by a labelled legend).
